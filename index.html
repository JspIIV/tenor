GenLayer Asimov

A public register that flags an output which passed every rule yet betrayed its brief.

An agent output can clear every mechanical check, no banned words, the right length, the right format, and still read wrong: off-tone, quietly selling something the brief forbade, missing the point it was made for. Open a brief, the intent and voice an output is meant to honour. Anyone can then submit a public output produced for it, and a round of GenLayer validators reads the output against the brief and rules whether it is off-brief, assuming the rules already pass. Every off-brief output is a permanent strike. A brief with no strikes is not certified good; it only means nobody has yet shown an output that betrays it.
